# “交作业”视觉规范

实现基准：

- `popup-concept.png`：扩展弹窗主界面。
- `settings-concept.png`：设置页桌面布局。

设计令牌：

- 背景：纯白 `#FFFFFF`；侧栏：`#F7F5F3`。
- 强调色：北大红风格的深红 `#9E0E0F`；悬停 `#7F0809`。
- 正文：`#17191D`；辅助文字：`#727780`；分隔线：`#E6E1DC`。
- 字体：系统无衬线中文字体；代码与模板使用等宽字体。
- 控件圆角为 8–10px；页面采用开放式分区和细分隔线，不使用卡片网格或渐变。
- 身份由用户在设置页配置，只保存到浏览器本地扩展存储；自动填写与自动提交固定开启。

响应式：设置页在 760px 以下将左侧导航折叠为顶部横向导航，表单标签和输入框改为单列。

## 视觉验收账本

| 核对项 | 设计稿证据 | 最终渲染结果 |
| --- | --- | --- |
| 信息与顺序 | 弹窗依次为状态、仓库、两个开关和提交动作 | 文案与顺序一致，无额外营销内容 |
| 布局 | 设置页为左侧导航和单列表单 | 1584×992 原生设计稿尺寸下列起点、宽度与保存区一致 |
| 字体与控件 | 清晰中文层级、紧凑控件字级 | 标题、标签、辅助文字和按钮均定义明确字级 |
| 色彩与容器 | 纯白背景、深红强调、细灰分隔线、无卡片网格 | 色值锁定为规范令牌，未加入渐变或多余卡片 |
| 图标 | 书签勾选品牌图标、用户/齿轮/信息线性图标 | 使用生成的品牌 PNG 与同线宽 SVG 功能图标 |
| 响应式 | 侧栏在小屏折叠 | 390px 视口无横向溢出，字段和开关保持可读 |

有意差异：弹窗里的仓库区域使用可编辑输入框，而不是设计稿中的只读地址与复制按钮，以支持无法从仓库页自动识别时手动粘贴地址；用户要求固定开启自动提交后，主次两个按钮被收敛为单一“自动提交作业”动作。设置页原有的 Markdown 模板字段已移除，确保作业内容只能是远程仓库 URL。
